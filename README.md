# 커뮤니티 지원 허브

[Prestomedia](https://prestomedia.com/ko) 애플리케이션의 공식 공개 커뮤니티 지원 포럼에 오신 것을 환영합니다! 

이 공간은 사용자 간의 소통, 기능 요청 및 일반적인 Q&A를 위한 공간입니다. *본 포럼은 공개 커뮤니티 포럼*이라는 점을 참고해 주세요.



## 📱 애플리케이션을 선택하세요

질문, 문제 보고 또는 아이디어를 제안하려면 아래에서 해당 앱의 토론 카테고리를 클릭하세요:

* 📝 [**Free Text Editor**](https://github.com/PrestomediaLLC/community-ko/discussions/categories/free-text-editor-com)
* 📊 [**Pro Diagrams**](https://github.com/PrestomediaLLC/community-ko/discussions/categories/prodiagrams-com) (출시 예정)
* 📊 [**Free Diagrams**](https://github.com/PrestomediaLLC/community-ko/discussions/categories/freediagrams-com) (출시 예정)
* 📊 [**Team Matcher**](https://github.com/PrestomediaLLC/community-ko/discussions/categories/team-matcher-com) (출시 예정)

*(카테고리 안에서 **"New discussion"**을 클릭하면 작성 양식이 안내해 드립니다.)*



## 📋 커뮤니티 가이드라인

글을 작성하기 전에 다음 사항을 확인해 주세요:

1. **먼저 검색하기:** 해당 앱 카테고리에 기존 토론이 있는지 확인해 보세요. 이미 질문이나 기능 요청에 대한 답변이 있을 수 있습니다.
2. **개인정보 보호:** **개인 정보**, 이메일 주소, 비밀번호, 라이선스 키 또는 민감한 금융 데이터를 절대로 게시하지 마세요. 모든 게시글은 완전히 공개됩니다.
3. **상호 존중하기:** 다른 커뮤니티 회원들을 친절하게 대해 주세요. 친절하고 건설적인 토론은 모두를 위한 더 나은 앱을 만드는 데 도움이 됩니다!
